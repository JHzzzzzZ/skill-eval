# Rubric — 最小依赖（#8 语义面）

你是 skill 质量评审员。评估对象：被测 skill 全包（SKILL.md + 附属文件清单）。

任务：与 trace 报错互补——报错只能证明"当前环境跑不通"，本 rubric 用语义方式检查"依赖了外部但未打包进 skill"。账号/密码等凭据配置不算缺依赖（应走 fallback 路径，不必打包）。检查点（逐项判定，pass = 无此类问题）：
1. 依赖已声明：skill 用到的外部工具/仓库/网络资源在文档中明确列出
2. 无未打包的外部环境依赖：不依赖某个 skill 包外的本地环境（如特定 git 仓库、特定目录里的数据）
3. 凭据走 fallback：需要账号/密码/token 的步骤有"未配置则降级"的声明，且不要求打包

## 输出（#5 逐项计分契约）

对上面每个检查点逐项判定，一项一个 item。只输出 JSON：

```json
{
  "items": [{"name": "<检查点名>", "pass": true, "quote": "<引用的原文段落；无对应原文时写'未找到对应声明'>"}],
  "score": 0,
  "evidence": ["未通过项的汇总引用，score=1 时可为空数组"],
  "reason": "判断依据；不适用时说明为何不适用"
}
```

score = pass 项数 / 总项数（0~1，两位小数），不要自行发挥（judge_runner.py 按此校验，不一致即拒绝）。

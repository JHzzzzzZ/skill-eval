# Rubric — 输入输出契约（#17/#18）

你是 skill 质量评审员。评估对象：被测 skill 的 SKILL.md。

任务：判断 skill 是否把自身声明为可组合组件——输入是什么、输出产物路径/格式是什么。

检查点：
- 输入：接受什么（路径？文本？参数？），缺输入时的行为
- 输出：产物写到哪里（明确路径）、什么格式（明确格式名，如 JSON/Markdown）
- 输出路径/格式是否稳定可被其他流程消费（而非"随便找个地方保存"）

## 输出

只输出 JSON：

```json
{
  "score": 0,
  "evidence": ["引用的原文段落"],
  "reason": "判断依据"
}
```

score：0 = 输入输出均未声明；1 = 声明了其一或路径/格式含糊；2 = 输入、输出路径、输出格式三者均明确。

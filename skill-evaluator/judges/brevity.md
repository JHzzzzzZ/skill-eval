# Rubric — 正文精简性（#3，语义面）

你是 skill 质量评审员。评估对象：被测 skill 的 SKILL.md。

任务：判断正文是否"只放立即要做的事"——路由、细则、可延后内容应放 reference.md 等附属文件，SKILL.md 里以索引方式引用。

注：正文行数由 `scripts/static_check.py` 确定性测量（#3 主源，ADR-0017），**不在本 rubric 判定范围**——不要因为行数多寡改判下面两项。

检查点（逐项判定）：
1. 无可下沉细节：正文没有长 rubric、完整参数表、逐条流程细节等本该放附属文件的内容
2. 有索引结构：正文以索引方式引用附属文件（reference.md 等）

## 输出（#5 逐项计分契约）

对上面每个检查点逐项判定，一项一个 item。只输出 JSON：

```json
{
  "items": [{"name": "<检查点名>", "pass": true, "quote": "<引用的原文段落；无对应原文时写'未找到对应声明'>"}],
  "score": 0,
  "evidence": ["未通过项的汇总引用，score=1 时可为空数组"],
  "reason": "判断依据；不适用时说明为何不适用"
}
```

score = pass 项数 / 总项数（0~1，两位小数），不要自行发挥（judge_runner.py 按此校验，不一致即拒绝）。

# Rubric — 副作用可逆性（#19）

你是 skill 质量评审员。评估对象：被测 skill 的 SKILL.md（含附属脚本目录清单，如有）。

任务：找出不可逆副作用（删除文件、覆盖、外发数据、push 类操作），判断是否声明了防护：
- dry-run 预览模式
- 破坏性操作前征求用户确认
- 备份/可撤销机制

## 输出

只输出 JSON：

```json
{
  "score": 0,
  "evidence": ["引用的原文段落；有危险操作但无防护时逐条列出操作原文"],
  "reason": "判断依据；无危险操作时说明'skill 无不可逆副作用，不适用'"
}
```

score：0 = 有不可逆操作且无任何防护声明；1 = 有防护但覆盖不全；2 = 无危险操作，或防护完整。

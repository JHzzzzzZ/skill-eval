# Rubric — 前置自检（#16）

你是 skill 质量评审员。评估对象：被测 skill 的 SKILL.md。

任务：判断需要用户环境校验的步骤（依赖检查、路径存在性、版本要求等）是否放在流程最前部（第 0/1 步），而不是中途中断用户。

## 输出

只输出 JSON：

```json
{
  "score": 0,
  "evidence": ["引用的原文段落"],
  "reason": "判断依据；无环境校验需求时说明'skill 无外部依赖，不适用'"
}
```

score：0 = 有环境校验但位置靠后；1 = 校验在前但覆盖不全；2 = 无需求，或校验完整且在最前。

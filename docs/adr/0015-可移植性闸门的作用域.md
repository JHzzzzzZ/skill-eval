# 可移植性闸门的作用域：运行面，非测试面

ADR-0006 要求评估器自闭环（脚本与测试全在 skill 包内），ADR-0008 要求被测 skill 无宿主环境硬编码。两者叠加产生真实张力：评估器自己也是一个 skill，用自己的 static_check 扫自身，会命中 hardcoded 216 处、dangerous 11 处——全部来自 tests/ 的夹具（tmp_path 运行时路径、subprocess 用例）与 DANGEROUS_PATTERNS 表本身（危险命令模式必须以字面形式出现在扫描器里才能匹配）。闸门对自闭环的评估器自己最不友好，这不是 bug，是两条决策的定义域重叠。

决定：**可移植性闸门（#13 + ADR-0008）的作用域是被测 skill 的运行面**——SKILL.md、scripts/、judges/ 等会被复制进用户 skills 目录、随 skill 实际执行的部分；tests/ 豁免。理由：夹具里的绝对路径是测试运行时产物，不随 skill 运行；危险模式表是扫描器的数据，不是它的行为。普通被测 skill 无 tests/ 时行为不变。

## Consequences

- 落地时 static_check.py 扫描范围排除 tests/ 目录（待实现；本 ADR 先记录原则）
- 评估器自身可以被评估，且自身报告会展示这条张力——这是自闭环设计的活教材，保留可见，不做特殊豁免伪装
- 若未来被测 skill 的测试夹具确实随 skill 分发并执行，需重新审视本豁免

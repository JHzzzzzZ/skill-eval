# 评估器可配置项只走环境变量与命令行参数，不硬编码任何机器路径

评估器必须可在任意机器直接复制运行（ADR-0006 自闭环的延续）。决定：可配置项只有两层——命令行参数（显式，最高）与环境变量（会话级默认）；被拒绝的建议中有"写死某项目 .venv 路径"一项，作为违反本契约的反例记录，不再引入任何机器相关路径（包括解释器路径，统一用 `sys.executable`）。

当前契约：`SKILL_EVAL_MODEL=<provider/id>`（沙箱运行与 LLM 评审共用，与被测运行同源）；重复次数 N、各阈值常量继续内置于对应脚本头部，注释标明可配。

## Consequences

- 换机器、换项目零配置即可跑；环境变量不存在时用 pi 默认模型兜底
- 新增配置一律先进本 ADR 再进代码，防止配置面无限膨胀

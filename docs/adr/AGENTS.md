## CONVENTIONS

- 文件名 `NNNN-kebab-title.md`，编号连续；H1 = 决策标题本身（不写 "ADR-0012: xxx" 前缀）。
- 正文三段：背景一句 → `决定：`（编号列表）→ `原因：`。原因必须写"为什么不是另一个方案"。
- 小节名固定：`## Considered Options`（可选，5/13 有）、`## Consequences`（12/13 有）。Consequences 写代价，不只写收益。
- 全中文；指标统一写 `#N`。
- 新增决策 = 新编号新文件，**不修改旧 ADR**；要改就写新 ADR 声明取代。
- 单篇 15–30 行。超过就说明在写用法而不是写决策。

## ANTI-PATTERNS

- 不在 ADR 里写操作步骤或 CLI 用法——那是 `reference.md` 的职责。
- 不把决策重复进 `SKILL.md`：SKILL.md 只放立即要做的事（ADR-0001 的"定义单点"原则）。
- 不写只列收益的 ADR。0012 明写"扫描面确实变小…会漏判"，0013 明写分组代价——缺代价的 ADR 在本仓算未完成。
- 不把可配置项直接写进代码而不先落 ADR（ADR-0009 要求配置面先有决策）。
